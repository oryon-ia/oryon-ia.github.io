# ORYON

A IA de programação que nasce no seu PC: pensa à vista, escreve código avançado, roda os testes e corrige antes de entregar. Treinada do zero e rodando inteira na sua máquina.

**Página e download:** https://oryon-ia.github.io

Este repositório é só o site. Os executáveis ficam em [oryon-ia/oryon](https://github.com/oryon-ia/oryon/releases/latest).
